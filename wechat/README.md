状态：**图文内容草稿已整理；个人订阅号尚需用户本人注册；未在微信公众平台发布。**

## A 方案：个人订阅号（先做）→ 原生小程序（后续）

公众号承载「生活故事 + 文言新编 + 字词注音 + 经典对读 + 诵读仿写」；Vercel 主站继续提供点击字词注解、语音、跨期切换与相册功能。**不更换 Vercel 发布，不将相册 Token 接入微信，也不改变现有文章和进度键。**

注册入口：https://mp.weixin.qq.com/ → 立即注册 → 订阅号 → 个人主体；按平台当前页面要求完成邮箱/管理员微信/身份核验。账号昵称是否可用，以微信平台实际检查为准。

## 账号资料（可直接复制）

- 名称：**岁岁文章**
- 备选名称：**岁岁文章·家常古文**（仅当主名称不可用时使用；选前确认用户意愿）
- 简介：**记下家庭生活的真实故事，把日常写成文言。每期一篇生活随笔，配字词注音、经典对读与诵读仿写，让古文从日子里生长。**
- 栏目名称：**岁岁一篇｜字里寻章｜与古人共读｜诵读仿写**
- 文章栏目模板：引子 → 文言正文 → 字词卡 → 经典对读（注明出处、与本文关系） → 诵读仿写 → 网页版入口。
- 发布频率建议：每周一篇，先发两期，再评估阅读、分享与回访。

### 发布前检查

- 核对孩子/家庭照片及个人信息是否适合公开；第一版不用家庭真实照片也可以发布。
- 公众号头像、文章封面需单独上传或制作；本轮仅准备文字。
- 检查文言改写与孩子原作文的署名和区分，不将改写误称为孩子原作。
- 公众号正文里的 Vercel 网址可能以纯文本展示，不预设个人订阅号具有可直接跳转的外链功能。
- 微信公众平台图文编辑器中检查手机端排版、预览、手动发布。
- 首发完成后记录文章链接、阅读/分享数据、发布日期等 Evidence，再关闭发布 Gate。
