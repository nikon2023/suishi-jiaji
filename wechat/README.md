- 名称：**岁岁有新章**
- 品牌主张：**常有文章，岁岁成章。**
- 品牌寄语：**岁岁有新章，年年有故事。话以常事，写岁月诗。让每一段成长，都成为值得珍藏的篇章。**
- 品牌内涵：“岁岁”代表时间、成长与陪伴；“有”代表持续记录；“新章”既是一篇新的文章，也是家庭生活的新篇章。

- 简介：**记下家庭生活的真实故事，把日常写成文言。每期一篇生活随笔，配字词注音、经典对读与诵读仿写，让古文从日子里生长。**
- 栏目名称：**岁岁一篇｜字里寻章｜与古人共读｜诵读仿写**

- 发布频率建议：每周一篇，先发两期，再评估阅读、分享与回访。

### 发布前检查

- 核对孩子/家庭照片及个人信息是否适合公开；第一版不用家庭真实照片也可以发布。
- 公众号头像、文章封面需单独上传或制作；本轮仅准备文字。
- 检查文言改写与孩子原作文的署名和区分，不将改写误称为孩子原作。
- 公众号正文里的 Vercel 网址可能以纯文本展示，不预设个人订阅号具有可直接跳转的外链功能。
- 微信公众平台图文编辑器中检查手机端排版、预览、手动发布。
- 首发完成后记录文章链接、阅读/分享数据、发布日期等 Evidence，再关闭发布 Gate。
